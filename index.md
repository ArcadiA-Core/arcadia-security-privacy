## ArcadiA Security Privacy Policy
Last updated: October 23, 2026

### **Introduction**
   
ArcadiA Security is a Discord bot that provides moderation, server management, invite tracking, supporter roles, and other utility features.

This Privacy Policy explains what information ArcadiA Security processes, how it is used, where it may be stored, and how users can request assistance with their data.



### **Information We Process**

Depending on the features enabled by a Discord server, ArcadiA Security may process the following information:

- Discord identifiers: User IDs, server IDs, channel IDs, role IDs, and message IDs where required by a feature.
  
- Server configuration: Settings such as prefixes, autorole configuration, audit-log configuration, and other feature settings.
  
- Moderation information: Records of moderation actions, including relevant user IDs, action types, reasons, and timestamps where recorded.
  
- Invite information: Invite codes and invite related information used to support invite tracking.
  
- Command information: Messages containing bot commands, command arguments, and slash command interactions when necessary to provide the requested functionality.
  
- Supporter verification: Discord presence information used to check whether a member's custom status contains "/enticed" for supporter role eligibility.
  
- Feature-specific information: Data needed for features such as AFK, clans, tournaments, and leaderboards, when those features are used.

The information processed depends on the features used by each server.



### *How Information Is Used*

ArcadiA Security uses information only as needed to provide its features, including:

- Executing authorized moderation and server management commands.
  
- Assigning roles and supporting server configuration.
  
- Tracking invites and maintaining invite related statistics.
  
- Checking supporter eligibility using the configured "/enticed" status requirement.
  
- Maintaining moderation records and audit logs.
  
- Supporting clans, tournaments, leaderboards, and other enabled utilities.
  
- Troubleshooting errors and maintaining the bot.



### **Message Content**

ArcadiA Security processes message content when needed to recognize and execute its prefix commands, which begin with "_", and to handle relevant command arguments.

The bot may also process information supplied through slash commands, buttons, menus, and forms.

***Message content is not used to train AI or machine learning models.***
Storage: Whether command messages, arguments, or moderation reasons are retained depends on the relevant feature. The operator should document any persistent message content storage and its retention period accurately.



### **Presence and Supporter Roles**
ArcadiA Security uses Discord presence information to check whether a member's custom status contains "/enticed", as required by the server's supporterrole feature.

This check is used to determine supporter role eligibility. Presence information is not intended to be used for unrelated tracking.

Members who do not wish to display the required status can choose not to display it, but may consequently be ineligible for the supporter role.

Presence data is not intentionally retained as a historical activity log unless a feature is specifically implemented to do so.



### **Storage and Retention**

ArcadiA Security may store information outside Discord, including in files or other storage used by the bot operator to maintain server settings, invite data, moderation records, and feature state.

Information is retained for as long as reasonably necessary for the relevant feature, unless a different retention period is required or appropriate.

The operator should periodically review stored information and remove data that is no longer needed.



### **Sharing and Disclosure**

***ArcadiA Security does not sell users' personal information.***
Information may be processed by Discord and by the infrastructure or service providers required to operate the bot. Information may also be visible to authorized server staff through relevant moderation or server management features.
Information will not intentionally be disclosed to unrelated third parties except where required for service operation, legal compliance, or protection against abuse.



### **Data Requests and Deletion**

Users and server administrators may request information about data associated with their use of ArcadiA Security or ask for eligible data to be deleted.
Requests can be submitted through the contact method listed below.

Requests will be reviewed and handled where reasonably possible and in accordance with applicable requirements.
Some information may need to be retained temporarily for legitimate moderation, security, or operational reasons.



### **Security**

Reasonable measures should be used to protect stored information and bot credentials from unauthorized access. No method of electronic storage or transmission can be guaranteed to be completely secure.



### **Changes to This Policy**

This Privacy Policy may be updated when ArcadiA Security's features or data practices change. The date at the top indicates the most recent revision.
